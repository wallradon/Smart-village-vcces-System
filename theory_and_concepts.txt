                    เนื้อหาและรายละเอียดของระบบ (Project Details & Content)
                  โครงการ: ระบบ Smart Village VCCES System (IoT Project)
================================================================================

1. ภาพรวมของระบบ (Project Overview)
--------------------------------------------------------------------------------
Smart Village VCCES System คือ เว็บแอปพลิเคชันสำหรับบริหารจัดการและตรวจสอบข้อมูล
ภายในหมู่บ้านอัจฉริยะ ออกแบบมาเพื่อเป็นส่วนหน้าจอ (Frontend Interface) สำหรับผู้ดูแลระบบ 
และใช้เชื่อมต่อกับอุปกรณ์ฮาร์ดแวร์ IoT ในอนาคต เช่น กล้องอ่านป้ายทะเบียนรถยนต์อัตโนมัติ (LPR) 
และระบบไม้กั้นสแกนเปิด-ปิดประตูทางเข้า-ออก


2. ฟังก์ชันการทำงานหลักของระบบ (Main Features)
--------------------------------------------------------------------------------
2.1 ระบบยืนยันตัวตนและการป้องกันเส้นทาง (Authentication & Route Protection)
    - ตรวจสอบสิทธิ์การเข้าใช้งาน (Login Guard) ผ่าน sessionStorage
    - หากผู้ใช้ยังไม่ได้เข้าสู่ระบบ ระบบจะนำทางกลับไปหน้า login.html อัตโนมัติ
    - มีระบบ Logout เพื่อล้างข้อมูลการเข้าใช้งานชั่วคราวอย่างปลอดภัย

2.2 สถาปัตยกรรมสลับหน้าจอแบบหน้าเดียว (Single Page Application - SPA Navigation)
    - สามารถสลับการแสดงผลระหว่างหน้าหลัก (Home), ข้อมูลยานพาหนะ (Vehicle Data), 
      และข้อมูลลูกบ้าน (User Data) ได้อย่างรวดเร็วโดยไม่ต้องโหลดหน้าเว็บใหม่
    - ควบคุมการแสดงผลหน้าจอด้วย Attribute `data-target` ในการเปิด-ปิด `.page`
    - มีระบบไฮไลต์เมนูข้าง (Sidebar Navigation) ให้สอดคล้องกับหน้าจอที่เปิดใช้งานอยู่

2.3 ระบบตรวจสอบและบันทึกประวัติการเข้า-ออกยานพาหนะ (Vehicle Entry-Exit Monitoring)
    - แสดงรายการประวัติการเข้า-ออกของยานพาหนะทุกรอบ
    - แสดงประเภทของยานพาหนะ (รถยนต์ / รถจักรยานยนต์), หมายเลขทะเบียนรถ, 
      และบันทึกเวลาเข้า-ออกอย่างแม่นยำ (Time-In / Time-Out)
    - จัดเรียงข้อมูลในรูปแบบตารางที่ดูง่าย ชัดเจน และสบายตา

2.4 โครงสร้างจัดการข้อมูลลูกบ้าน (Resident & Data Layer Architecture)
    - ดึงและประมวลผลข้อมูลจากไฟล์ JSON จำลอง (dataTest.json)
    - แสดงรายชื่อลูกบ้าน, บ้านเลขที่, วันที่สมัครสมาชิก, และวันหมดอายุสมาชิก
    - รองรับโครงสร้างข้อมูลแบบซ้อนกัน (Nested Data Structure) เช่น ลูกบ้าน 1 คน 
      สามารถมีรถยนต์ได้หลายคัน และรถแต่ละคันมีประวัติเข้า-ออกได้หลายรอบ

4. เครื่องมือและเทคโนโลยีที่ใช้พัฒนา (Technology Stack)
--------------------------------------------------------------------------------
- HTML5 : โครงสร้างหน้าเว็บแบบ Semantic Elements และ SPA Containers
- CSS3  : การตกแต่งด้วย CSS Variables, Flexbox, Grid Layout และ Responsive Design
- JavaScript (ES6+) : Async/Await, Fetch API, Event Delegation, DOM Manipulation 
                      และ Session Management
- JSON  : ใช้เป็น Mock Data จำลองโครงสร้างข้อมูลจาก Backend API


5. แผนการพัฒนาต่อยอดในอนาคต (Future Enhancements)
--------------------------------------------------------------------------------
- Backend Integration : เชื่อมต่อระบบหน้าบ้านกับ RESTful API หรือ Database จริง 
                        (เช่น Node.js Express, Firebase, PostgreSQL)
- Hardware & IoT Integration : เชื่อมต่อสัญญาณกล้องอ่านป้ายทะเบียน (ALPR) 
                                และเซ็นเซอร์เปิด-ปิดไม้กั้นแบบ Real-time ผ่าน MQTT/WebSocket
- Full CRUD Operations : เพิ่มระบบ ฟอร์มสำหรับ เพิ่ม/แก้ไข/ลบ ข้อมูลลูกบ้าน 
                         และลงทะเบียนป้ายทะเบียนรถใหม่ผ่านหน้า Admin Panel
