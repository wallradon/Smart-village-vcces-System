1 วัตถุประสงค์ของระบบ (Goal)

Smart Village VCCES System คือระบบบริหารจัดการการเข้า-ออกของยานพาหนะ ภายในหมู่บ้านอัจฉริยะ ช่วยให้ผู้ดูแลระบบ (Admin) ตรวจสอบประวัติรถเข้า-ออก บันทึกเวลา และดูแลความปลอดภัยของลูกบ้านได้อย่างมีประสิทธิภาพ ผ่านหน้าเว็บ (Web Application)

6 แนวคำถาม-ตอบ สำหรับนำเสนอ

Q1: โปรเจกต์นี้ทำงานอย่างไร?

ตอบแบบ ELI5: ระบบนี้ทำงานเหมือน "ป้อมยามอัจฉริยะ" มี 2 ส่วนหลัก

  1. ส่วน Login (login/) — เหมือนประตูตรวจสอบสิทธิ์ ยามเช็กว่าชื่อผู้ใช้และรหัสผ่านถูกต้องไหม ถ้าถูกจะให้ "บัตรผ่าน" เข้าสู่ระบบ
  2. ส่วน Admin Dashboard (admin/) — เหมือนห้องควบคุมหลัก แสดงสมุดลงทะเบียนรายชื่อบ้าน ทะเบียนรถ และเวลาเข้า-ออกย้อนหลัง โดยใช้ JavaScript ดึงข้อมูลจากไฟล์ JSON มาแสดงผลแบบไดนามิก
Q2: ในหน้า Login มีการทำงานของ JavaScript อย่างไร?

ตอบแบบสรุปเทคนิค: เราใช้แนวคิด DOM Selection และ Event Listener

  • เมื่อผู้ใช้กดปุ่ม Submit ใช้ event.preventDefault() เพื่อไม่ให้หน้าเว็บ Refresh
  • นำค่าจากช่อง username และ password มาเช็กกับข้อมูล Mock Data
  • ถ้าถูกต้อง สั่งเปลี่ยนหน้าด้วย window.location.href = '../admin/admin.html'
  • ถ้าผิด สั่งให้ Element แจ้งเตือนเปลี่ยนสถานะเป็น display: block
Q3: ทำไมต้องใช้ ?? '-' (Nullish Coalescing)?

ตอบแบบสรุปเทคนิค: ใช้เป็น Fallback Value (ค่าสำรอง) ในกรณีที่ข้อมูลจากไฟล์ JSON ส่งค่ามาเป็น null หรือ undefined (เช่น รถบางคันยังไม่มีประวัติเวลาออก) ตัว ?? จะช่วยนำข้อความ fallback คือ '-' มาแสดงแทน เพื่อไม่ให้หน้าเว็บขึ้นคำว่า null หรือเกิดข้อผิดพลาด

Q4: โปรเจกต์นี้เชื่อมโยงกับ IoT อย่างไรในอนาคต?

ตอบแบบภาพรวม IoT: ระบบนี้สามารถนำไปเชื่อมต่อกับอุปกรณ์ IoT Hardware ได้ เช่น

  • กล้องอ่านทะเบียนรถ (ALPR Camera / ESP32-CAM): เมื่อรถขับผ่านป้อมยาม กล้องจะส่งเลขทะเบียนผ่าน API/MQTT เข้ามายังระบบหลังบ้าน
  • ไม้กั้นอัตโนมัติ (Servo / Relay): ถ้าเช็กแล้วเป็นรถลูกบ้านในระบบ จะส่งสัญญาณสั่งเปิดไม้กั้นอัตโนมัติ พร้อมบันทึกเวลาเข้า (timeIn) ลงฐานข้อมูล

7 โค้ดตัวอย่าง (Code Highlights)

login.js — การตรวจสอบสิทธิ์
// ตรวจสอบสิทธิ์ (Authentication Check)
loginForm.addEventListener("submit", function (event) {
    // ป้องกันการ Refresh หน้าเว็บ
    event.preventDefault();

    if (inputUsername === MOCK_USER.username
        && inputPassword === MOCK_USER.password) {
        // ออกบัตรผ่านและพาไปหน้า Admin
        sessionStorage.setItem("isLoggedIn", "true");
        window.location.href = "../admin/admin.html";
    } else {
        errorMessage.style.display = "block";
    }
});
script.js — Fallback ด้วย ??
// ถ้าไม่มีข้อมูลให้แสดง '-' แทน null
vehicleData.timeInOut.forEach((timeRecord) => {
    timeInHTML += `
    <span class="time-record">
        ${timeRecord.in ?? '-'}
    </span>`;
    timeOutHTML += `
    <span class="time-record">
        ${timeRecord.out ?? '-'}
    </span>`;
});
