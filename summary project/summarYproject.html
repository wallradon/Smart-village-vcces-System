PROJECT SUMMARY & ARCHITECTURE

Smart Village VCCES System

ระบบจัดการข้อมูลลูกบ้าน ยานพาหนะ และเวลาเข้า-ออก โครงการหมู่บ้านจัดสรรอัจฉริยะ (IoT)

📍 RMUTL ENGCP_3 🏷️ Frontend & Data Layer ⚡ Responsive & SPA

📌 ภาพรวมโปรเจกต์ (Project Overview)

Smart Village VCCES System เป็นเว็บแอปพลิเคชันสำหรับบริหารจัดการและตรวจสอบข้อมูลภายในหมู่บ้านอัจฉริยะ ออกแบบมาเพื่อเป็นส่วนหน้าจอ (Frontend Interface) ในการเชื่อมต่อกับระบบฮาร์ดแวร์ IoT เช่น กล้องอ่านป้ายทะเบียนอัตโนมัติ (LPR) และระบบไม้กั้นสแกนเข้า-ออก

🚀 ฟีเจอร์หลักของระบบ (Main Features)

🔐 1. Authentication & Route Protection

  • ตรวจสอบสิทธิ์การเข้าใช้งาน (Login Guard) ด้วย sessionStorage
  • หากยังไม่ได้ล็อกอิน จะดีดกลับไปยังหน้า login.html อัตโนมัติ
  • ระบบ Logout ล้าง Session ชั่วคราวปลอดภัย

📱 2. Single Page Application (SPA) Navigation

  • การสลับหน้าจอ (Home, Vehicle Data, User Data) โดยไม่ต้องโหลดเว็บใหม่
  • ใช้ Attribute data-target ในการควบคุมการเปิด-ปิด .page
  • ระบบไฮไลต์แถบเมนูข้าง (Sidebar Navigation) ให้ตรงกับหน้าปัจจุบัน

🚗 3. Vehicle Entry-Exit Monitoring

  • แสดงรายการประวัติการเข้า-ออกยานพาหนะทุกรอบการเข้าออก
  • แสดงประเภทรถ (Car / Motorcycle), ทะเบียนรถ และเวลาเข้า-ออก (`in ... out ...`)
  • จัดเรียงตำแหน่งคอลัมน์และข้อความชิดซ้าย/กลาง/ขวาเพื่อความสบายตา

👥 4. Resident & Data Layer Architecture

  • ดึงและประมวลผลข้อมูลจากไฟล์ JSON จำลอง (`dataTest.json`)
  • แสดงรายชื่อลูกบ้าน บ้านเลขที่ วันสมัครสมาชิก และวันหมดอายุ
  • รองรับโครงสร้างแบบ Nested Array (ลูกบ้าน 1 คน มีรถหลายคัน และมีประวัติเข้าออกหลายรอบ)

🛠️ เทคโนโลยีที่ใช้ (Technology Stack)

เทคโนโลยี / ส่วนประกอบ รายละเอียด & หน้าที่
HTML5 โครงสร้างหน้าเว็บแบบ Semantic Elements และ SPA Containers
Vanilla CSS3 การจัดตกแต่งด้วย CSS Variables, Flexbox, Grid Layout และ Responsive Media Queries
Vanilla JavaScript (ES6+) Async/Await, Fetch API, Event Delegation, DOM Manipulation และ Session Management
JSON (Mock Data) จำลองโครงสร้างข้อมูลจาก Backend API สำหรับทดสอบระบบ
