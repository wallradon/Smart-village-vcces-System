# Admin Dashboard (ระบบจัดการหน้าเว็บ)

หน้าเว็บ Admin ถูกออกแบบมาให้เป็นระบบหน้าเดียว (Single Page Application - SPA) เพื่อความรวดเร็วในการใช้งาน โดยมีการแบ่งสัดส่วนของการแสดงผลด้วยการใช้ `display: none` และ `display: block` ใน CSS ร่วมกับการจัดการผ่าน JavaScript

## โครงสร้างเมนูนำทาง (Navigation Menu)
ระบบประกอบไปด้วย 3 เมนูหลัก ได้แก่:
1. **HOME (`data-target="home"`)**: 
   - หน้าหลักของระบบ (ปัจจุบันอยู่ระหว่างการพัฒนา)
2. **VEHICLE DATA (`data-target="vehicle"`)**: 
   - หน้าแสดงข้อมูลยานพาหนะของลูกบ้านแต่ละหลัง (ปัจจุบันอยู่ระหว่างการพัฒนา)
3. **USER DATA (`data-target="user"`)**: 
   - หน้าแสดงรายชื่อลูกบ้านทั้งหมด
   - สามารถคลิกที่รายชื่อเพื่อดูรายละเอียดเพิ่มเติมของลูกบ้านแต่ละคนได้

## การจัดการข้อมูล (Data Management)
ในฝั่งของ Frontend ระบบจะใช้ไฟล์ `admin/dataTest.json` เป็นแหล่งข้อมูลจำลอง (Mock Data) 

### การทำงานของ `script.js`
ไฟล์ `script.js` มีหน้าที่หลักดังนี้:
- **Navigation Logic**: 
  - เมื่อผู้ใช้คลิกเมนู ระบบจะดักจับเหตุการณ์คลิกและทำการอ่านค่าจาก Attribute `data-target` 
  - จากนั้นจะนำค่าดังกล่าวไปแมปกับ ID ของ `<section class="page">` เพื่อแสดงหน้าเนื้อหาที่สอดคล้องกับเมนูที่เลือก และซ่อนหน้าอื่น ๆ ไว้
- **Data Fetching**: 
  - ทำการใช้คำสั่ง `fetch()` เพื่ออ่านข้อมูลจาก `dataTest.json`
- **Data Rendering (User Data)**:
  - วนลูป (Loop) ข้อมูลลูกบ้านที่อ่านมาได้
  - สร้าง Element HTML แบบไดนามิก (Dynamic HTML Creation) เพื่อแทรกข้อมูลเข้าไปในตารางแสดงผลในส่วนของ `section#UserData`
- **User Detail View**:
  - เมื่อคลิกดูรายละเอียดของลูกบ้าน ระบบจะสร้าง Element แสดงรายละเอียดเพิ่มเติม เช่น ชื่อเจ้าของบ้าน, วันที่ลงทะเบียน, จำนวนยานพาหนะ ฯลฯ และเปลี่ยนหน้าการแสดงผลไปยัง `section#page-userDetail`

## โครงสร้างของข้อมูลจำลอง (`dataTest.json`)
ข้อมูลลูกบ้านที่ระบบดึงมาแสดงผลมีโครงสร้างพื้นฐานดังนี้:
```json
{
  "users": [
    {
      "id": 1,
      "houseNumber": "123/45",
      "ownerName": "นาย ก ทดสอบ",
      "vehicles": [...]
    }
  ]
}
```
