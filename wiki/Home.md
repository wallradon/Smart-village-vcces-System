# ภาพรวมของระบบ (Overview)

**Smart Village VCCES System** เป็นระบบจัดการข้อมูลลูกบ้านสำหรับหมู่บ้านอัจฉริยะ โดยมุ่งเน้นการจัดการข้อมูลพื้นฐานของลูกบ้านและยานพาหนะผ่านหน้าเว็บ (Web Application)

## วัตถุประสงค์ของระบบ
- เพื่อเป็นศูนย์กลางในการตรวจสอบและจัดการข้อมูลของลูกบ้านแต่ละหลัง
- ตรวจสอบยานพาหนะที่ลงทะเบียนไว้กับทางหมู่บ้าน (อยู่ระหว่างการพัฒนา)
- อำนวยความสะดวกให้ผู้ดูแลระบบ (Admin) ในการเข้าถึงข้อมูลของลูกบ้านอย่างรวดเร็ว

## โครงสร้างของระบบหน้าเว็บ (Frontend)
ระบบในส่วนของ Frontend ถูกพัฒนาด้วยเทคโนโลยีพื้นฐานของเว็บ ได้แก่:
- **HTML**: เป็นโครงสร้างหลักของหน้าเว็บ มีทั้งหน้าต้อนรับ (Landing Page), หน้าเข้าสู่ระบบ (Login) และหน้ากระดานควบคุม (Admin Dashboard)
- **CSS**: ใช้สำหรับตกแต่งหน้าเว็บให้มีความสวยงามและรองรับการแสดงผลแบบทันสมัย (Modern Design)
- **JavaScript**: ใช้สำหรับจัดการการทำงานของระบบ เช่น การเข้าสู่ระบบด้วย Session Storage, การป้องกันหน้าเว็บ (Route Guard), และการดึงข้อมูลจากไฟล์ JSON มาแสดงผล

## ภาพรวมไฟล์ที่ใช้งานหลัก
- **Root Directory:**
  - `index.html`: หน้าพนักงานต้อนรับ (Landing Page / Smart Router) 
  - `indexStyle.css`: ไฟล์ตกแต่งสไตล์เฉพาะสำหรับหน้าต้อนรับ
- **Login Module (`login/`):**
  - `login.html`: หน้าจอสำหรับกรอกชื่อผู้ใช้และรหัสผ่าน
  - `login.css`: การตกแต่งหน้าต่างเข้าสู่ระบบ
  - `login.js`: ตรวจสอบสิทธิ์ (Authentication) และออกบัตรผ่าน (Session Storage)
- **Admin Module (`admin/`):**
  - `admin.html`: ไฟล์หลักในการแสดงผล Admin Dashboard (ป้องกันการเข้าถึงหากไม่ได้ล็อกอิน)
  - `style.css`: ไฟล์สไตล์ชีทหลักสำหรับจัดรูปแบบธีม
  - `script.js`: ไฟล์ลอจิกจัดการ Session Guard, จัดการเหตุการณ์ และดึงข้อมูลลูกบ้าน
  - `dataTest.json`: ไฟล์ฐานข้อมูลจำลอง (Mock Data) สำหรับทดสอบระบบ
