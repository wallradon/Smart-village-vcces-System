# ภาพรวมของระบบ (Overview)

**Smart Village VCCES System** เป็นระบบจัดการข้อมูลลูกบ้านสำหรับหมู่บ้านอัจฉริยะ โดยมุ่งเน้นการจัดการข้อมูลพื้นฐานของลูกบ้านและยานพาหนะผ่านหน้าเว็บ (Web Application)

## วัตถุประสงค์ของระบบ
- เพื่อเป็นศูนย์กลางในการตรวจสอบและจัดการข้อมูลของลูกบ้านแต่ละหลัง
- ตรวจสอบยานพาหนะที่ลงทะเบียนไว้กับทางหมู่บ้าน (อยู่ระหว่างการพัฒนา)
- อำนวยความสะดวกให้ผู้ดูแลระบบ (Admin) ในการเข้าถึงข้อมูลของลูกบ้านอย่างรวดเร็ว

## โครงสร้างของระบบหน้าเว็บ (Frontend)
ระบบในส่วนของ Frontend ถูกพัฒนาด้วยเทคโนโลยีพื้นฐานของเว็บ ได้แก่:
- **HTML (`index.html`)**: เป็นโครงสร้างหลักของหน้าเว็บ แบ่งออกเป็นส่วนเมนูนำทาง (Navigation) และส่วนแสดงเนื้อหา (Pages)
- **CSS (`style.css`)**: ใช้สำหรับตกแต่งหน้าเว็บให้มีความสวยงามและรองรับการแสดงผลแบบทันสมัย (Modern Design)
- **JavaScript (`script.js`)**: ใช้สำหรับจัดการการทำงานของระบบ เช่น การคลิกเมนูเพื่อสลับหน้าเว็บ (SPA - Single Page Application แบบเบื้องต้น) และการดึงข้อมูลจากไฟล์ JSON มาแสดงผล

## ภาพรวมไฟล์ที่ใช้งานหลัก
- `admin/index.html`: ไฟล์หลักในการแสดงผล Admin Dashboard
- `admin/style.css`: ไฟล์สไตล์ชีทสำหรับจัดรูปแบบ
- `admin/script.js`: ไฟล์ลอจิกในการดึงข้อมูลและจัดการเหตุการณ์ต่าง ๆ บนหน้าเว็บ
- `admin/dataTest.json`: ไฟล์ฐานข้อมูลจำลอง (Mock Data) สำหรับทดสอบระบบก่อนนำไปต่อกับ Backend ของจริง
