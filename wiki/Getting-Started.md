# วิธีการเริ่มต้นใช้งานระบบ (Getting Started)

เอกสารนี้จะแนะนำวิธีการเปิดใช้งานระบบหน้าเว็บ Admin (Frontend) ของโปรเจกต์ **Smart-village-vcces-System** สำหรับการรันบนเครื่องคอมพิวเตอร์ของคุณ

## สิ่งที่ต้องเตรียม (Prerequisites)
ก่อนที่คุณจะสามารถทดสอบระบบได้ คุณจำเป็นต้องมี:
- Web Browser (เช่น Google Chrome, Microsoft Edge, Safari)
- โปรแกรม Code Editor (แนะนำให้ใช้ **Visual Studio Code (VS Code)**)
- ส่วนขยาย (Extension) **Live Server** สำหรับ VS Code (เพื่อให้สามารถจำลอง Web Server และอ่านไฟล์ `dataTest.json` ได้อย่างถูกต้อง)

## วิธีการเปิดใช้งาน
เนื่องจากโปรเจกต์นี้มีการใช้คำสั่ง `fetch()` ใน JavaScript เพื่อโหลดข้อมูลจากไฟล์ JSON หากคุณเปิดไฟล์ `index.html` โดยตรงด้วยการดับเบิลคลิก Browser อาจจะบล็อกการโหลดข้อมูลด้วยเหตุผลด้านความปลอดภัย (CORS Policy) ดังนั้น **เราแนะนำให้เปิดผ่าน Live Server**

### ขั้นตอนการรันผ่าน VS Code:
1. เปิดโปรแกรม **Visual Studio Code**
2. เลือกเมนู **File > Open Folder...** จากนั้นเลือกโฟลเดอร์โปรเจกต์ `Smart-village-vcces-System`
3. ในแถบ Explorer ด้านซ้ายมือ ให้เปิดโฟลเดอร์ `admin` และคลิกที่ไฟล์ `index.html`
4. เมื่อไฟล์ `index.html` เปิดขึ้นมา ให้คลิกขวาที่พื้นที่ว่างในหน้าต่าง Code แล้วเลือกคำสั่ง **"Open with Live Server"** (หรือคลิกปุ่ม `Go Live` ที่แถบสถานะด้านล่างขวาของโปรแกรม)
5. Web Browser ของคุณจะเปิดแท็บใหม่ขึ้นมาพร้อมกับ URL คล้าย ๆ กับ `http://127.0.0.1:5500/admin/index.html`

### การทดสอบระบบ
1. เมื่อหน้าเว็บโหลดขึ้นมา ระบบจะอยู่ที่หน้าต่าง **HOME**
2. ให้ลองคลิกที่เมนู **USER DATA** จากนั้นระบบจะแสดงรายชื่อลูกบ้านขึ้นมา
3. คุณสามารถคลิกที่รายชื่อลูกบ้านเพื่อดูข้อมูลจำลองทั้งหมดได้เลย
